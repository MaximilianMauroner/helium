# Feature coverage

No reliable full product audit exists. The shared patch tree supplies this
initial feature map. Each unreviewed group needs a native feature inventory and
operator-selected journey before a full browser acceptance claim.

| Surface | Coverage |
| --- | --- |
| [Compact layout and window grab area](compact-layout.md) | Partial: candidate/native evidence required |
| UI layouts, tabs, toolbar and browser chrome | Partial: Compact slice only |
| Browser core and page loading | Not covered |
| Networking, privacy and service controls | Not covered |
| Branding, localization and resource loading | Not covered |
| Extension behavior and platform integration | Not covered |

Native platform packaging has its own source and revision. Upstream remotes,
release hosting and background links do not qualify those repositories for an
additional audit without substantive task evidence.
